# Trap Under — Monografía Web

## Descripción del Proyecto
**Trap Under** es una monografía web interactiva enfocada en el **Trap Hispanoamericano**. El sitio combina una maquetación responsiva con una estética urbana estilo *zine / DIY* (recortes, sombras duras y tipografía tipo máquina de escribir), ofreciendo un recorrido visual por los exponentes clave, la cronología histórica del movimiento y una sección de videoteca.

## Tecnologías Utilizadas
* **HTML5:** Estructura semántica de la página.
* **CSS3:** Personalización de estilos, aplicando de forma obligatoria las propiedades `display` y `position`.
* **Bootstrap 5 (CDN):** Framework para maquetación y componentes interactivos.

## Componentes de Bootstrap Implementados
1. **Navbar:** Navegación superior responsiva para desplazarse por la página.
2. **Grid System (`container`, `row`, `col`):** Organización de columnas adaptables a computadora, tablet y celular.
3. **Cards:** Tarjetas de contenido con estilo personalizado.
4. **Badges:** Etiquetas estilo sello/pegatina posicionadas sobre los elementos.
5. **Accordion:** Línea del tiempo desplegable estructurada en 4 etapas.
6. **Ratio (Embeds):** Contenedores responsivos para la integración de videos.

## Estructura de Archivos
* `index.html`: Código fuente y maquetación de la monografía.
* `styles.css`: Hoja de estilos propios con las reglas de `position`, `display` y diseño visual.
* `assets/`: Carpeta que almacena todas las imágenes del proyecto en un mismo formato.
